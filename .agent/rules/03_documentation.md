# ドキュメント

## ドキュメントの作成

- このリポジトリのドキュメントはルートの `README.md` のみです (docs サイトはありません)。
- イメージ・egg・起動コマンド・変数のデフォルト値などを変更したら、`README.md` の該当する節 (Images / Paper egg / Velocity egg / Notes / Verification / Runtime comparison) を合わせて更新してください。
- `README.md` は英語で書かれています。追記も英語で、既存の文体に合わせてください。
- 数値 (ヒープサイズ、起動時間、コンテナの上限など) は実測した値だけを書き、どう測ったかを Verification 節に残してください。
- なお、文章の文体について、その他の部分で指示があったとしても、ドキュメントに関しては、あくまでも文章の文体で記載してください。
